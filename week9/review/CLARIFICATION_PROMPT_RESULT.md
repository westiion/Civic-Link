| 지표 | 현재 지침 | 확인 질문 지침 추가 |
|---|---:|---:|
| 필요한 정보를 충분히 되물은 확인 질문형 | 0/6 | 0/6 |
| 필요한 정보 일부를 실제로 되물은 확인 질문형 | 1/6 | 1/6 |
| 필수 내용을 유지하고 불필요하게 되묻지 않은 대조군 | 2/2 | 2/2 |

## 공유할 내용

확인 질문을 먼저 하라는 지침을 추가한 뒤에도 **충분한 확인 질문은 0/6**이었다. 특히 현재 화면을 확인해야 하는 사례에서 채널을 가정하는 답이 나왔다. 질문·근거를 고정한 답변 단계 비교이므로, 전체 검색 흐름이나 다른 모델의 결과에는 이 수치를 일반화하지 않는다.

다음으로 시험할 변경은 `W7V2-BH002` 한 문항에서 **현재 채널을 판정할 정보가 있는지 확인하는 단계**를 별도로 두는 것이다. 채널이 확인되지 않으면 인터넷과 무인발급기 중 어느 쪽인지 묻고, 채널이 주어진 대조 입력에서는 해당 채널의 규칙을 안내하는지 확인한다. 응답 지침의 정식 반영이나 전체 실행 확대는 그 비교 결과로 판단한다.

# Week 8 · 추가 질문형 6문항 검수

60문항 평가 표본의 추가 질문형 6개를 대상으로 A(단일 검색), B(반복 검색), C(반복 검색+Graph)의 답변 18개를 벤치마크 기준, 자동 채점 사유, 실행 기록과 대조했다. 조건별 일반 안내를 함께 하는 것은 허용한다. 답변이 사용자에게 필요한 정보를 실제로 요청했는지, 해당 응답만으로 개인 적용 결과를 확정했는지를 따로 확인했다. 문장에 물음표가 없어도 필요한 정보를 알려달라는 표현은 질문으로 인정했다.

**결과** · 18개 답변 모두 정상 종료했고, 기존 자동 채점에서 모두 `answer`로 분류되어 A/B/C 각각 0/6이었다. 검수에서는 16개가 확인 질문 없이 답했고, 2개는 필요한 정보 일부를 물었다. 두 부분 확인 사례에서도 같은 턴에서 적용 결과를 선택할 수 있는 핵심 정보가 남아 있어, 이 표본에서 충분한 확인 질문을 한 답변은 찾지 못했다. 아래 검수는 저장된 답변과 기준을 대조한 결과이며 기존 점수를 변경하지 않았다.

## 실행 기록에서 확인한 점

- 여섯 문항의 공통 첫 검색을 제외하면 B에서 추가 `search` 선택이 7회, C에서 5회 있었다. C의 실제 `graph` 선택은 0회였다. 유형별로 검색을 더 하면 일반 규정은 찾을 수 있지만, 어떤 서류·화면·필지인지처럼 사용자가 가진 정보는 확인 질문이 필요하다.
- 세 조건 모두 최종 프로토콜 행동은 `respond`였다. 현재 프로토콜에서 `respond`는 직접 답변과 확인 질문을 모두 담을 수 있으므로, 확인 질문 여부는 응답 텍스트를 보고 판단했다.
- 기존 점수의 0/6에는 실제 확인 질문 누락이 주로 반영됐다. 다만 부분 질문을 전부 일반 답변으로 처리하거나, 조건부 설명을 개인별 확정으로 해석한 자동 채점 사유가 있었다. 재평가할 때는 **실제 확인 요청 여부**, **필수 정보 충족**, **미확인 조건을 단정했는지**를 각각 확인하는 편이 적절하다.

## 후속 비교 기준

같은 여섯 문항에서 검색 설정을 고정하고, 사용자에게만 확인할 수 있는 정보가 부족할 때 필요한 질문부터 하는지 비교한다. 서류명·화면·소재지처럼 필요한 정보를 실제로 요청했는지, 이미 주어진 사실을 다시 묻지 않았는지, 조건부 일반 설명을 덧붙인 경우 개인별 결과까지 확정하지 않았는지를 기록한다. 우선 비교 사례는 **채널 하나만 확인하면 되는 `W7V2-BH002`**와 **부분 질문만 나온 `SJ-X-050`, `W7-BH021`**이다.

# Civic-Link — Problem Definition


## 목적

수정구 무인민원발급 관련 대표 서비스를 대상으로 시민과 개인사업자가 필요한 증명서, 발급 조건, 법적 근거를 공식 자료에서 확인하도록 지원하는 Administrative-Legal Graph RAG Agent를 연구한다.

서비스 안내와 법령 조문을 연결하여 검색하고, 답변의 주장마다 근거를 제시한다. 필요한 증거 또는 신청 맥락이 부족하면 추가 정보를 요청하거나 판단을 유보한다.


## 연구 범위

Core Service는 10개 분야의 증명 서비스 36개다. 서비스 정의, 증명 내용, 공개된 신청 요건·구비서류·본인확인, 일반 발급 채널, 관련 법령과 직접 참조 조문을 포함한다.

발급기 위치·동선·운영시간·실시간 장애, 개인정보 조회, 증명서 실제 발급, 인허가·신고 접수, 전문 업종 규제, 금융기관의 심사 및 개별 사건의 법적 판단은 제외한다. 특정 서비스가 무인발급 대상이라는 사실과 개별 기기의 지원 여부를 구분한다.


## 근거 사용 정책

지역 발급 목록과 전국 공통 법령의 역할, 창구·온라인·무인발급의 조건을 구분한다. 조회일과 법령 시행일을 별도 기록한다. 기준일 이후 시행되는 법령은 기준일의 정답에 적용하지 않는다.

출처 충돌이 해결되지 않은 수수료·관할 조건은 정답으로 고정하지 않는다. 개인별 신청 가능 여부에 학교·졸업연도 등 추가 맥락이 필요한 경우 그 정보 없이 가능·불가능을 단정하지 않는다.

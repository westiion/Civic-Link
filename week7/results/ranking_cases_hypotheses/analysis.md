# 가설 1 분석: 출처·내용 편중 완화

## 결론

현재 설정에서 내용 유사도 감점은 전체 완전회수를 437→440으로 소폭 개선했다. 그러나 여러 근거 종합 유형은 31/48→28/48로 악화했고, 대표적인 비교 편중 사례도 해결하지 못했다. 따라서 ‘편중을 줄이면 비교 질문의 필수 근거가 더 잘 남는다’는 주장을 전반적으로 지지하지 않는다. 출처 감점은 평균 출처 편중을 줄였지만 성능을 낮췄다.

## 전체 결과

| 조건 | 완전회수@10 | Recall@10 | MRR@10 | 완전 성공 획득 / 상실 |
|---|---:|---:|---:|---:|
| BGE | 437/488 | 93.26% | 0.8336 | — |
| 출처 감점 | 428/488 | 92.65% | 0.8327 | 4 / 13 |
| 내용 감점 | 440/488 | 94.01% | 0.8333 | 6 / 3 |
| 둘 다 | 427/488 | 92.58% | 0.8320 | 6 / 16 |

내용 감점 Recall은 약 0.75%p 증가, 완전회수 비율은 약 0.61%p 증가했다. MRR은 소폭 낮아져 모든 지표 개선은 아니다. 부분 회수 변화를 포함하면 내용 감점은 7문항 개선·4문항 악화다.

## 관찰과 해석

- 출처 감점에서 top10의 최다 출처 청크 수 평균은 4.82→3.57로 줄었다. 다양성 증가와 정답 근거 회수 증가는 같지 않다.
- SJ-A-003: BGE 근거 순위 63/1/24. 출처 감점은 3/1/25로 정부24 근거를 회복했지만 같은 성남시 문서의 예외 행은 여전히 누락했다. 내용 감점은 63/1/24로 불변이다.
- W7V2-MS042: 국세·등기 근거 순위가 모든 조건에서 55/1로 같다. 출처 감점은 top10 출처 수를 3→8로 늘렸지만 국세 쪽 필수 근거는 회복하지 못했다.
- W7V2-LA010: 내용 감점으로 두 필수 그룹이 속한 청크가 11→10위로 올라 완전회수를 달성했다. 두 그룹 회복이 두 청크 추가라는 뜻은 아니다.
- SJ-N-061: 휴업·폐업 비교의 두 근거가 BGE 4/2위에서 내용 감점 11/2위가 되어 성공을 잃었다.
- W7-MS-023: 졸업증명·생활기록부 연도 비교에서 7/1→11/1위로 악화했다.
- W7-MS-044: 두 급여의 소득인정 범위 비교에서 2/9/1→2/11/1위로 악화했다.

마지막 세 사례는 비교에 함께 필요한 근거까지 유사도 감점으로 제외될 수 있음을 보여준다. 의미적으로 유사한 문서를 중복으로 취급하는 정책의 한계이며, 질문의 하위 요구를 충족했는지를 직접 판단한 결과가 아니다.

## 검증과 범위

608문항의 모든 조건에서 전체 후보 집합과 ID의 중복 없음을 확인했다. 기준선 437/488을 재현했다. rankings.jsonl, protocol.json, vectors.sqlite의 SHA-256이 rank.run.json과 일치했다. 회사 임베딩 캐시는 5,474청크·4,096차원으로 완료됐다. 첫 5개 이후 5,469개 요청 시간은 약 480초, 순위 계산은 약 9.76초였다.

가중치 0.15, 코사인 문턱 0.8에서의 개발셋 결과다. 새로운 독립 검증이나 통계적 우월성을 주장하지 않는다. 서버 내부 모델 revision·잘림 설정은 확인되지 않았다. 청크 회수 평가이며 답변 생성 정확도가 아니다.

## 다음 실험

출처 감점을 기본 정책으로 채택하지 않는다. 내용 감점은 후보 개선안으로 보존하되 비교 질문 회귀를 함께 보고한다. 다음 가설은 기존 BGE 기준선에서 독립적으로 검증해 효과를 분리한다. 이번 내용 감점을 다음 실험에 자동 누적하지 않는다.

# 가설 2 분석: 질문과 관련된 명시적 참조 대상 선택

## 결론

명시적 REFERENCES 대상에 상위 순위를 배정하면 일부 연결 근거 누락을 해결하지만, 이번 설정에서는 전체 완전회수 성능이 개선되지 않았다. 질문과 참조 대상의 임베딩 유사도로 선택하는 방식의 추가 효과도 확인하지 못했다. 두 참조 조건 모두 기존 성공 5문항을 잃고 4문항을 회복했다.

## 비교 조건

가설 1의 감점을 누적하지 않고 같은 기존 BGE 순위에서 독립적으로 실험했다. 후보 집합과 최종 반환 수 10개를 고정했다.

- `bge_direct`: 기존 BGE 순위 유지.
- `references_bge`: 상위 7개를 보호하고, 해당 청크를 근거로 하는 출발점의 정방향 REFERENCES 대상 중 기존 후보에 있는 조항 근거를 BGE 점수순으로 최대 3개 선택.
- `references_semantic`: 동일한 참조 후보에서 질문·대상 청크의 코사인 유사도순으로 최대 3개 선택.

이미 보호된 상위 7개에 근거가 있는 대상 조항은 제외하고, 대상 조항마다 최대 한 청크를 선택한다. 남은 순서는 기존 BGE 순서를 유지한다. 새 청크를 후보 밖에서 가져오는 실험이 아니라, 기존 후보 안에서 참조 근거의 순위를 조정하는 실험이다. 의미 유사도의 최소 문턱이나 질문별 참조 필요성 판단은 적용하지 않았다.

회사 Qwen 임베딩 API로 질문 벡터를 만들고 가설 1의 청크 벡터를 재사용했다. BGE를 다시 추론하지 않았다.

# 가설 3 분석: 질문 목적과 근거 역할 정렬

## 결론과 비교 조건

질문별 역할 비중으로 점수를 보완하면 완전회수가 437→438문항으로 한 문항 증가했다. Recall@10 악화 문항은 없지만 MRR은 소폭 감소했다. 한 사례의 제한적인 개선 신호이며, 전반적으로 효과가 검증됐다고 결론내리기에는 부족하다.

H1/H2의 순위 조정을 누적하지 않고 기존 BGE 후보와 점수를 사용했다. 서비스·준비물·절차·자격·기간·수수료·법적 근거·기재 범위의 설명문 8개에 대한 임베딩 유사도를 역할 비중으로 변환했다(softmax temperature=0.05). 최종 점수는 문항 내 min-max BGE + 0.15 × 질문·청크 역할 비중의 내적이다. 역할 비중은 검수된 분류 확률이 아니다.

평균 역할 대조군은 개별 질문 대신 전체 질문의 평균 역할 비중을 사용한다. 특정 역할 자체를 선호하는 효과와 질문별 정렬 효과를 구분하기 위한 개발셋 진단용 대조군이다. 정답은 순위 계산에 사용하지 않았다.

|---|---:|---:|---:|---:|---:|
| 기존 BGE | 437/488 | 93.26% | 0.8336 | 481 | — |
| 평균 역할 대조군 | 437/488 | 93.26% | 0.8330 | 481 | 0 / 0 |

질문별 정렬의 Recall@10과 완전회수 비율은 각각 약 0.20%p 증가했다. 개선 문항은 W7V2-LA014 한 개다. legal_grounding 완전회수는 54/60→55/60이며 다른 유형은 동일하다. multi_source_multi_hop은 31/48로 그대로다.

W7V2-LA014는 종이로 신청한 폐업사실증명을 처리 후 찾아가지 않은 경우의 종결 시점과 전자문서의 차이를 규정으로 묻는다. 정답표의 필수 청크 `DOC-1bac55fd50fbfb130cff-C0024`는 기존 BGE 11위, 평균 역할 대조군 11위, 질문별 정렬 10위였다.

# 다섯 실험 종합 비교

모든 실험은 같은 BGE 기준선과 기존 후보에서 독립적으로 실행했다. 아래는 각 가설의 주요 조건이며, H1은 출처 감점이 아닌 내용 유사도 감점 조건이다. 각 절의 대조군 결과도 함께 검토해야 한다.

| 조건 | 완전회수@10 | Recall@10 | MRR@10 | 완전회수 개선 / 악화 |
|---|---:|---:|---:|---:|
| 기준선 | 437/488 | 93.26% | 0.8336 | 0 / 0 |
| H1 내용 중복 감점 | 440/488 | 94.01% | 0.8333 | 6 / 3 |
| H2 의미 기반 참조 선택 | 436/488 | 93.21% | 0.8336 | 4 / 5 |
| H3 질문별 역할 정렬 | 438/488 | 93.46% | 0.8330 | 1 / 0 |
| H4 같은 조항 인접 청크 | 437/488 | 93.39% | 0.8338 | 2 / 2 |
| H5 BGE·임베딩 RRF | 380/488 | 83.66% | 0.6556 | 12 / 69 |

## 판단

- H1 내용 감점은 전체 완전회수·Recall에서 가장 높지만 비교·다중 근거 질문의 회귀와 MRR 감소가 있어 잠정 개선 후보로 보존한다. 출처 감점은 악화했으므로 함께 적용하지 않는다.
- H3는 한 문항 개선으로 제한적인 신호만 확인했다. 역할 판정 검수와 별도 검증이 필요하다.
- H2와 H4는 구조적 연결을 이용해 특정 근거를 회복했지만, 질문별 필요성을 판단하지 않고 자리를 배정하면 기존 근거를 밀어내는 공통 한계를 보였다.
- H5 동일 가중치 결합은 손실이 커 채택하지 않는다. 임베딩을 추가한다는 것 자체가 개선을 보장하지 않는다.

다섯 방법을 함께 적용한 실험은 하지 않았다. 개별 개선 문항 수를 더해 결합 성능으로 주장할 수 없다. 모두 기존 분석에 사용한 개발셋의 정답표 기준이며 독립 검증, 법률적 원문 검수 완료, 생성 답변 정확도를 뜻하지 않는다. 최종 보고에서는 개선안뿐 아니라 부정적 결과와 구체적인 순위 손실 원인을 함께 제시한다.

이 부록은 전체 608문항 중 이 그룹의 15문항이다. 검색 결과와 실제 답변 품질은 구분한다.

중요도: 보류·추가 확인 → 응답 또는 검색 우선 검토 → 지속 검색 실패 → 일부 복구 → 검색 성공. 같은 그룹 안에서는 누락 근거 수와 BGE 근거 순위, 비답변은 최고 관련도 점수 순으로 검토한다. 관련도 점수는 행동 실패 점수가 아니다.

조건 번호는 ① 기존 수식, ② 기존 수식 뒤 전체 BGE, ③ 변경 수식, ④ 변경 수식 뒤 전체 BGE다. 순위는 각 근거를 인정하는 청크 중 가장 높은 순위이며, 10위 밖이면 완전회수에 기여하지 않는다.

행동 불일치나 사후 모델 채점의 내용 미충족이 있는 답변 문항도 우선도 3에 포함했다. 그룹 안에서는 모델의 미지원 단정 표시, 내용 미충족, 행동 불일치 순으로 먼저 본다. 모델 채점은 사람 확정이 아니며 원문 발췌 불일치도 별도 표시한다. 동일한 입력의 응답은 재사용했다.

## 최초 진단 기록 · 512토큰

512토큰 평가에서도 순위 탈락은 44문항이었다. 이 중 필수 문장이 잘린 6문항의 후보를 고정하고 입력 길이만 늘리자 5문항을 회복했다. 당시에는 이 5문항을 제외한 **39문항**에서 실패 원인을 분석했다. 이후 답변 가능 488문항 전체를 1,024토큰으로 채점하자 512토큰에서 실패했던 6문항이 성공하고, 성공했던 다른 6문항이 실패했다. 최초 진단 39문항과 현재 순위 탈락 44문항에서 겹치는 문항은 38개다. [6문항 입력 길이 비교](results/bge-length-512-vs-1024.json) · [최초 39문항 상세 분석](ranking-cases-512.md) · [보고서의 전체 재평가](../REPORT.md#22-입력-길이-보정과-실패-사례-분석)

최초 39문항 중에서 선정한 유형 1의 14문항과 유형 4의 순방향 인용 7문항에는 1,024토큰에서도 각각 Graph 순위와 인용 가점을 시험했다. 이 실험의 분모 14와 7은 당시 선정한 문항 수다. [Graph 순위 비중별 결과](results/t4-1024-graph-type1-summary.csv) · [상위 조항의 인용 가점별 결과](results/t4-1024-top10-citation-summary.csv)

## 후보 누락 7문항

최초 Graph 탐색 기록을 대조했을 때 누락된 7개 묶음은 모두 그래프의 원문 근거와 연결돼 있었다. 각 질문의 시작점과 탐색 경로에서는 이 청크를 수집하지 못했다. 512토큰 순위에서 5문항은 놓친 묶음이 모두 후보 밖에 있었고, 2문항은 다른 근거도 10위 밖으로 밀렸다.

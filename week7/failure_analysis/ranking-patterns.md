# 순위 탈락 44문항의 반복 패턴

대상은 기존 **Hybrid+Graph → BGE 직접 정렬**에서 모든 필수 근거가 100위 안에 있었지만 완전회수@10에 실패한 **44문항**이다. 놓친 근거 묶음은 51개다. 순위에서 보이는 양상, 정답표가 허용한 청크의 범위, 512토큰 입력 잘림을 따로 살폈다. [44문항 원문과 개별 순위](ranking-cases.md)

## 3. BGE 입력 512토큰에서 필요한 문장이 보였나?

기존 실행은 질문과 ‘청크 제목 + 줄바꿈 + 본문’을 합쳐 최대 512토큰으로 채점했다. 초과하면 질문은 보존하고 후보 쪽 끝을 자른다. 기존 모델과 같은 토크나이저 파일로 입력을 다시 만들었고, 44문항 각각의 원래 토큰 총수·최댓값·잘린 후보 수가 실행 기록과 일치했다. [실행 코드](../results/experiment2_20261031/executed_runner.py) · [실행 설정](../results/experiment2_20261031/bge.run.json)

- 전체 후보 **4,958개 질문–청크 쌍 중 781개**에서 끝부분이 잘렸다. 44문항 모두 후보 중 하나 이상이 잘렸지만, 그 후보가 정답이었다는 뜻은 아니다.
- 놓친 근거 51묶음 중 **9문항의 12묶음**에서 허용 청크 자체가 잘렸다(중복을 뺀 질문–청크 쌍 11개). 그중 **6문항의 6묶음**은 벤치마크에 인용된 필수 문장이 통째로 512토큰 밖에 있었다. 나머지 6묶음은 청크 끝이 잘렸어도 필요한 문장은 남았다.

예를 들어 W7-LA-024는 정답 청크의 본문이 **830자**까지 입력에 남았는데, 신청 포기 유도 금지 문장은 **903번째 글자**에서 시작했다. W7V2-LA010은 한 청크에서 제1항은 보였고 제4항은 잘렸다. 그래서 청크 길이만으로 판정하지 않고 각 묶음의 실제 인용 위치를 확인했다.

**청크는 잘렸지만 필요한 문장은 남은 문항**도 있다. [W7V2-PR017](ranking-cases.md#w7v2-pr017) · [W7V2-MS014](ranking-cases.md#w7v2-ms014) · [W7V2-MS043](ranking-cases.md#w7v2-ms043)에서는 놓친 근거의 인용문이 모두 입력 범위에 있었다. 위 표의 W7V2-LA010과 W7V2-MS044에는 입력 밖의 묶음과 입력 안의 묶음이 함께 있다.

### 같은 후보에서 512토큰과 1,024토큰 비교

필수 문장 전체가 512토큰 밖에 있던 6문항에서 같은 질문·후보·BGE 모델로 입력 한도를 비교했다. 후보 660개 중 512토큰을 넘은 **104개**는 1,024토큰으로 다시 채점했고, 입력이 같았던 **556개**는 기존 점수를 사용했다. 가장 긴 입력은 757토큰이었다. 새 조건에서는 정답 청크와 경쟁 후보 모두에서 잘렸던 뒷부분 전체가 점수에 반영된다.

**완전회수@10은 0/6 → 5/6, 완전회수@100은 6/6 → 6/6**이었다. 잘렸던 필수 문장이 있는 청크의 최종 순위는 상승 6문항, 동일 0문항, 하락 0문항이었다.

| 문항 | 잘렸던 근거의 최종 순위<br>512 → 1,024 | 상위 10개에서 찾은 묶음<br>512 → 1,024 | 상위 100개에서 찾은 묶음<br>512 → 1,024 |
|---|---:|---:|---:|
| [W7-LA-024](ranking-cases.md#w7-la-024) | 18위 → **1위** | 0/1 → 1/1 | 1/1 → 1/1 |
| [W7V2-LA010](ranking-cases.md#w7v2-la010) | 11위 → **1위** | 0/2 → 2/2 | 2/2 → 2/2 |
| [W7V2-LA016](ranking-cases.md#w7v2-la016) | 18위 → **1위** | 0/1 → 1/1 | 1/1 → 1/1 |
| [W7V2-MS007](ranking-cases.md#w7v2-ms007) | 21위 → **1위** | 1/2 → 2/2 | 2/2 → 2/2 |
| [W7V2-MS037](ranking-cases.md#w7v2-ms037) | 23위 → **13위** | 4/5 → 4/5 | 5/5 → 5/5 |
| [W7V2-MS044](ranking-cases.md#w7v2-ms044) | 65위 → **6위** | 1/3 → 3/3 | 3/3 → 3/3 |

W7V2-MS037에서는 기본증명서의 성별 기재 근거가 23위에서 **13위**로 올랐지만 필요한 5묶음 중 4묶음만 상위 10개에 남았다. W7V2-MS044에서는 평면도 열람의 일반 요건이 65위에서 **6위**, 임차인 예외가 12위에서 **10위**로 올라 세 묶음을 모두 회수했다.

문항별 Recall@10 평균은 27.22% → 96.67%였다. 이 결과는 입력 잘림으로 선별한 여섯 실패 사례(개발 5, 검증 1)에 한정한다. [660개 후보의 원점수와 순위](./results/bge-length-512-vs-1024.csv) · [실행 조건과 문항별 지표](./results/bge-length-512-vs-1024.json)

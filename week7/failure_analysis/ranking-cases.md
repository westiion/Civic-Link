# 순위 탈락 사례 · 분석 대상 39문항

Hybrid+Graph → BGE 직접 정렬(512토큰)에서 순위 탈락으로 분류한 44문항 중, 입력 길이를 보정해 완전회수@10에 성공한 5문항은 분석 대상에서 뺐다. 아래 목록에는 **39문항**이 남는다. 이 중 38문항은 512토큰 결과로 분석하며, [W7V2-MS037](#w7v2-ms037)은 1,024토큰으로 다시 채점해도 기본증명서의 성별 기재 근거가 13위였다.

[39문항의 반복 패턴](ranking-patterns.md) · [입력 길이 보정으로 회수한 5문항](#입력-길이-보정으로-회수한-5문항) · [6문항의 보정 전후 순위](ranking-patterns.md#같은-후보에서-512토큰과-1024토큰-비교)

### 39문항의 기존 상위 10개에는 무엇이 있었나?

아래 표와 통계는 **분석 대상 39문항의 기존 512토큰 순위**에서 계산했다. 상위 10개에서 필요한 묶음 일부만 회수한 문항은 31개, 한 묶음도 회수하지 못한 문항은 8개였다.

| 놓친 근거의 원문 문서가 상위 10개에 있었나? | 문항 수 |
|---|---:|
| 놓친 묶음의 원문 문서가 모두 등장했다. 같은 문서의 다른 조항이나 안내 항목이 앞섰다. | 21 |
| 놓친 묶음의 원문 문서가 하나도 등장하지 않았다. | 16 |
| 놓친 묶음 중 원문 문서가 등장한 경우와 등장하지 않은 경우가 함께 있었다. | 2 |

39문항 중 21문항은 20위까지 보면 필요한 근거가 모두 모였다. 18문항에서는 BGE 10위 밖의 정답 청크가 Hybrid나 Graph에서는 10위 안에 있었다. 각 사례의 토글에서 원래 순위와 실제로 앞선 근거를 확인할 수 있다.

# Week 8 · 608문항 실험 결과

같은 608문항과 첫 검색 결과로 반복 검색과 Graph 추가의 효과를 비교했다. A는 한 번 검색, B는 반복 검색, C는 반복 검색에 Graph 조회를 선택할 수 있는 조건이다.

| 지표 · 평가 범위 | A | B | C |
|---|---:|---:|---:|
| **최종 입력의 필수 근거 완전회수율** · 답변형 488문항 | 89.14% (435/488) | 93.85% (458/488) | 94.26% (460/488) |
| 실제 인용의 필수 근거 완전회수율 · 답변형 488문항 | 85.86% (419/488) | 89.96% (439/488) | 90.37% (441/488) |
| **내용 통과율** · 표본 60문항 | 75.0% (45/60) | 71.7% (43/60) | 76.7% (46/60) |
| 실행 실패율 · 전체 608문항 | 0.33% (2/608) | 0.16% (1/608) | 0.49% (3/608) |
| 문항당 평균 시간 · 전체 608문항 | 35.0초 | 44.7초 | 46.6초 |

두 **근거 완전회수율**은 각각 최종 Qwen 입력과 실제 인용에서 문항별 필수 근거를 모두 포함한 비율이다. 위 표는 답변형 488문항 기준이다. 전체 평가 보고서의 근거 지표는 근거 주석이 있는 추가 질문·보류까지 포함한 551문항 기준이다.

## 응답 내용 평가

사전에 고른 60문항을 응답 생성에 사용한 것과 같은 Qwen 모델로 채점했다. 조건 이름을 가리고, 각 응답을 정답·채점 기준과 대조했다.

| 기대 응답 | 필수 처리 기준 | A 통과 | B 통과 | C 통과 |
|---|---|---:|---:|---:|
| 답변 | 요구한 내용을 모두 안내 | 43/48 | 41/48 | 45/48 |
| 추가 질문 | 답에 필요한 사용자 정보를 구체적으로 확인 | 0/6 | 0/6 | 0/6 |
| 보류 | 처리할 수 없는 범위와 이유를 안내 | 2/6 | 2/6 | 1/6 |

필수 처리를 충족하고, 사실 주장이 있는 경우 내용이 정확하며 제공 본문과 실제 인용이 주장을 뒷받침해야 통과한다. 근거 없는 주장과 실행 실패는 미통과로 집계했다. 내용 통과율은 통과 문항 수를 60으로 나눈 값이며, 일부 자동 채점 설명은 사람 검토가 필요하다.

## 결과 해석

- **A → B**에서 필수 근거를 모두 확보한 문항은 23개 늘었고, 표본에서 내용이 통과한 문항은 2개 줄었다.
- **B → C**에서는 근거 완전회수가 5문항 개선되고 3문항 퇴보해 2문항 순증했다. 개선된 5문항 중 실제 Graph 조회를 한 경우는 1문항이었다.
- **추가 질문형**은 세 조건 모두 표본 6문항에서 필요한 정보를 확인하는 기준을 충족하지 못했다.

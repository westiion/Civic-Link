## Civic-Link · Week 3

3주차에는 텍스트 검색만으로 찾기 어려운 행정·법률 정보의 관계를 탐색하기 위해 지식 그래프와 Graph Retriever를 구축했습니다. 그래프 검색이 BM25·Dense·Hybrid 검색에서 누락된 근거를 보완할 수 있는지 204개의 민원 질문을 대상으로 비교했습니다.

### 핵심 작업

- 민원형 평가 질문을 204개로 확대
- 행정 서비스, 필요 서류, 처리기관, 법령, 조문의 관계 구조화
- 그래프의 노드와 관계를 공식 원문에 연결하는 Evidence Policy 구축
- NetworkX 기반 Graph Retriever 구현
- 텍스트 검색과 그래프 검색의 근거 회수 성능 및 실패 사례 비교

### 주요 결과

- 답변 가능한 177개 질문 중 Hybrid가 139개에서 필수 근거를 모두 찾아 전체적으로 가장 높은 성능을 보였습니다.
- 조문 간 명시적인 참조를 따라가야 하는 일부 질문에서는 Graph 검색이 텍스트 검색에서 누락된 근거를 보완했습니다.
- 탐색 깊이를 늘리는 것만으로 성능이 계속 개선되지는 않았으며, 질문 유형에 따라 효과적인 검색 방식이 달랐습니다.
